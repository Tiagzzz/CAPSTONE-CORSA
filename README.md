# CAPSTONE-CORSA

Research repository for the Capstone x CORSA 2026 project: gathering data from trustworthy, reliable sources that is useful for CORSA.

Agent rules: see [CLAUDE.md](CLAUDE.md).

## Structure

| Folder | Contents |
| --- | --- |
| `docs/scope/` | Project scope and briefing documents |
| `meetings/` | Meeting recaps, date-prefixed |
| `research/internal/` | Research produced by the team |
| `sources/` | Source register ([sources.md](sources/sources.md)) |
| `data/raw/` | Data as obtained from sources |
| `data/processed/` | Cleaned/derived datasets |
| `reports/` | Findings and syntheses for CORSA |
| `tasks/` | Plans and [lessons learned](tasks/lessons.md) |

Every PDF has a Markdown version next to it (`x.pdf` → `x.md`); agents read the `.md` versions.

Note: `meetings/2026-10-05-meeting-4-recap.pdf` and `-v2.pdf` are two different versions of the Meeting 4 recap; both are kept.
