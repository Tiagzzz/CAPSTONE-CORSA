## Method notes

- PDFs and DOCX files were downloaded with `download_file_content` (base64, decoded locally). Google Docs were exported to PDF; their Markdown was made from the DOCX export (HSG, Anfrage) or from the `read_file_content` text (Market Entry).
- DOCX to Markdown: `pandoc` (GFM). Embedded images/charts are not reproduced and appear as `[Figure N: ...]` placeholders; the DOCX files keep them (the "Matthieu2" and Oakberry documents are chart-heavy, so read the DOCX for those visuals).
- PDF to Markdown: `pdftotext -layout`, one fenced block per page so tables keep their alignment.
- XLSX: kept as-is; CSVs contain cached values only (formulas are not preserved). The workbook README says v0.2 while the file name says v0.5.
- File names were normalized to lowercase, hyphenated and date-prefixed (date = Drive modified date). Original Drive names are recorded in the table above and in each `.md` header.
- Folder sorting was a judgment call: briefing and scope documents went to `docs/scope/`, all HSG team reports and the finance overview to `research/internal/`, the financial model to `data/raw/`. No meeting recaps were found in the folder.
