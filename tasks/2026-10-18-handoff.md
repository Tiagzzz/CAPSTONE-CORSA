## Token-saving rules (mandatory)

1. Work from the notes and `analysis/outputs/`, not the long reports. Open a report only for the specific claim you need: `grep -n` first, then read just those lines.
2. Never read a file over about 25k tokens in full (for example `row_index.json` or `model_summary.json`); query it with a script or grep.
3. Numbers come from the scripts. Re-run only the script you need. `run_all.py` includes the slow link check.
4. **Verification:** one fetch per source (for example `curl -sL` and grep for the value), at most about 5 tool calls per item; record the verdict and move on. No bot-challenge, login or paywall bypass. A blocked source is UNREACHABLE.
5. Use few sub-agents, each with small, file-owned tasks. Pass them file paths, not pasted content, and ask for reports of 200 words or fewer.
6. Write each report section once and condense at the end. Do not rewrite whole drafts.
7. Logs and messages stay terse: one line per item or step.
