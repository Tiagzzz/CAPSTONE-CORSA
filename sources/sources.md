Every source used in a dataset or report must be listed here (see CLAUDE.md §5).

Reliability tiers: 1 = official/primary, 2 = peer-reviewed/research institute, 3 = reputable industry research/major news, 4 = other (leads/anecdotal only).

Accessed: "2026-10-16; opened" means the page was opened in run 1b (a relay page counts as opened for the relay only, not for the original it quotes). "snippet-only (not opened)" entries remain provisional; the reason is given where the host blocked access (bot challenge or access denied, never bypassed). Entries BEH-037 to BEH-064 and DEM-020 to DEM-027 were added in run 1b. Where the registered Bisnis.com or other relay URL could not be opened, the figure was checked on a substitute source registered under its own ID; the original entry is kept.
